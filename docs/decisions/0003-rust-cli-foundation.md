# ADR-0003: Rust CLI 기반과 사전 점검 계약

- 상태: 부분 대체 — MSRV 결정은 ADR-0011
- 날짜: 2026-07-31

## 배경

Rust 변환기를 구현하기 전에 입력·출력 경로, 사전 선택, 병렬도와 안전 기본값을
명시적인 CLI 계약으로 고정해야 합니다. 이 단계에서 XML 변환이나 EPUB 생성을
시작하면 경로와 실패 정책이 구현 세부에 섞여 이후 변경 비용이 커집니다.

## 결정

- 패키지와 실행 파일 이름은 `korean-dict-epub`으로 합니다.
- Rust 2024 edition을 사용하고 당시 MSRV는 Rust 1.85로 둡니다. 현재 MSRV는
  [`ADR-0011`](0011-rust-1-95-msrv.md)이 대체합니다.
- CLI 파서는 `clap` 4.6 계열과 derive API를 사용하며 `Cargo.lock`을 커밋합니다.
- KDEP-001에서는 `preflight` 명령만 제공합니다. 이 명령은 XML을 읽거나 출력
  디렉터리를 만들지 않고 경로와 실행 정책만 확인합니다.
- 기본 입력은 `references/korean-dict-nikl`, 기본 출력은 `outputs/rust`입니다.
- 사전 선택은 `all`, `krdict`, `stdict`, `opendict`입니다.
- 병렬도는 1 이상의 정수이며 기본값은 1입니다.
- 덮어쓰기와 실패 후 계속 실행은 각각 `--overwrite`, `--keep-going`을
  명시한 경우에만 허용하는 계약으로 둡니다.
- 출력 경로가 입력 경로를 포함하거나 입력 경로 안에 있으면 거부합니다.
- CLI 사용 오류는 종료 코드 2, 사전 점검의 입력·경로 오류는 종료 코드 3과
  `KDEP-E###` 형식의 오류 코드를 사용합니다.
- 설정 파일은 도입하지 않습니다. 반복되는 실제 사용 사례가 생긴 뒤 별도
  결정으로 추가합니다.

## 이유

- `clap`은 help, enum 값, 0이 아닌 병렬도와 사용 오류를 일관되게 검증합니다.
- Rust 1.85는 Rust 2024 edition과 선택한 `clap` 버전이 요구하는 최소 버전을
  함께 만족합니다.
- 사전 점검을 실제 변환과 분리하면 서브모듈이나 출력 파일을 건드리지 않고
  경로·정책 오류를 빠르게 확인할 수 있습니다.
- 표준 라이브러리 오류 타입을 사용하면 현재 단계에 별도 오류 프레임워크가
  필요하지 않습니다.

## 결과

- 현재 Rust CLI는 변환기가 아니라 KDEP-001 사전 점검 기반입니다.
- `build`, `validate`, `audit`와 XML/EPUB 처리는 이후 티켓에서 추가합니다.
- KDEP-001 자동 테스트는 작은 임시 디렉터리 fixture만 사용하며 원본
  서브모듈과 생성 EPUB을 수정하지 않습니다.
- 이 결정 당시 MSRV 1.85 검증 계획은 이후 dependency 변경으로 대체됐습니다.
  현재 MSRV와 검증 근거는 ADR-0011을 따릅니다.
