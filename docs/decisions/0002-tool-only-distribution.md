# ADR-0002: 콘텐츠 없는 변환 도구만 공개 배포

- 상태: 채택
- 날짜: 2026-07-31

## 배경

이 프로젝트는 외부 원본 XML을 읽어 개인 독서용 EPUB을 생성합니다. 변환
도구는 공개할 수 있지만, 원본 데이터와 생성 EPUB은 도구의 MIT License 적용
범위 밖이며 이 프로젝트의 배포 대상이 아닙니다. 도구 배포와 콘텐츠 배포의
상태를 분리하지 않으면 저장소나 릴리스에 원본·파생 콘텐츠가 잘못 포함될 수
있습니다.

## 결정

- Rust CLI의 소스와 실행 바이너리, 테스트, 사용 문서를 공개 배포합니다.
- 공개 저장소에는 upstream 원본 저장소를 가리키는 서브모듈 포인터만
  유지하며, 원본 XML을 부모 저장소나 릴리스 산출물에 복제하지 않습니다.
- 생성 EPUB, 검사 보고서와 미디어 파일은 공개 저장소와 릴리스에 포함하지
  않습니다.
- 사용자는 입력 데이터를 별도로 준비하고 도구는 로컬 변환만 수행합니다.
- 도구에는 원본 데이터, 생성 EPUB이나 보고서를 업로드·게시하는 기능을
  추가하지 않습니다.
- 생성 콘텐츠의 공개 배포는 이 프로젝트의 범위에서 제외합니다.

## 이유

- 변환 코드의 공개와 원본·파생 콘텐츠의 권리 조건을 명확히 분리할 수 있습니다.
- 릴리스 산출물에서 대용량 데이터와 개인 생성물을 구조적으로 제외할 수
  있습니다.
- 도구의 MIT License가 원본 데이터나 생성 EPUB까지 재라이선스한다는 오해를
  방지합니다.

## 결과

- 도구 릴리스 전에 파일 목록과 라이선스 고지를 별도로 검증해야 합니다.
- 새 환경의 사용자는 원본 입력을 별도로 준비해야 합니다.
- 전체 코퍼스 검증과 실제 리더 QA가 완료돼도 생성 EPUB은 배포 대상이 되지
  않습니다.
- 향후 콘텐츠 배포가 필요해지면 현재 범위를 확장하는 별도 결정과 권리 검토가
  선행되어야 합니다.
